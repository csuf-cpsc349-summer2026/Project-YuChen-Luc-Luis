## Getting Started
To get a local copy up and running, follow these steps.
### Prerequisites

    - A modern web browser
    - Node.js and npm
    - IDE (VS Code)
    - Clone of our repository
### 1. Navigate to the project directory:

    cd [repo-name]

### 2. Create your own .env file from our .env.example
    Insure .env is in .gitignore to not commit API Keys
### 3. Install Dependencies

    *In /client*
    npm install
    npm run dev
### 4. Run Development
    In main root:
    npm run dev
